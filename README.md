# 影の里 — Kage Village

직접 만든 일본 산골 마을 테마의 **플레이 가능한 첫 버전**입니다. 모델은 Roblox 에셋 ID가 아닌 JSON 데이터로 배포합니다. GitHub의 raw 파일을 읽어 로컬 Part/WedgePart 모델로 복원합니다. 모델 데이터 안의 코드는 실행하지 않습니다.

2026-10-14 실제 Roblox 클라이언트에서 GitHub raw 로딩, 마을 생성, 카메라 전환 및 배경음 로드/재생 상태를 확인했습니다. 전체 플레이·프레임률·최종 화면 품질은 아직 검증되지 않았습니다. 고해상도 텍스처나 전문 조형 메시를 사용한 완성형 게임이 아니라, 독자적으로 만든 부품 기반 환경과 괴물입니다.

## 포함 내용

- 760 × 800 스터드 지형, 약 6,400개 환경 부품. 주택 16채와 신사, 기와·쇼지·다다미 실내, 묘지, 우물, 등불, 숲과 산 배경.
- 세 종류의 괴물 모델: 흰 장막의 여인, 빈 얼굴의 승려, 붉은 문지기.
- 순찰, 시야 및 달리기 소리 감지, 추적, 봉인 다섯 개 수집, 종 울리기, 탈출 및 재도전.
- 직접 합성한 바람·저음·발소리·종·속삭임·긴장 효과 WAV 6개.
- 자동 안개·색보정·블룸·피사계 심도·등불. 외부 ReShade 실행이나 엔진 셰이더 교체는 하지 않습니다.
- 입장 시 카메라를 로컬 마을로 전환합니다. 실제 아바타는 원래 서버 맵에 남습니다. 서버에서 아바타가 사망하거나 재생성되면 종료합니다.

## 먼저 로컬에서 테스트

1. 압축을 풀어 `KageVillage` 폴더 전체를 실행기의 `workspace` 폴더 안에 넣습니다.
2. `PLAY-LOCAL.luau`를 실행합니다.
3. 현재 캐릭터 앞에 생긴 붉은 문에 접근하고 **E**를 누릅니다.
4. **R**로 입구를 현재 위치 앞으로 옮길 수 있습니다. 마을 밖에서만 작동합니다.

필요 기능: `readfile`, `loadstring`, WAV용 `getcustomasset`(또는 `getsynasset`), `writefile`, `makefolder`. 일반 Roblox LocalScript는 실행기 전용 파일 API를 제공하지 않습니다. 오디오가 지원되지 않으면 경고를 표시하며 게임은 소리 없이 진행됩니다. 메시지가 표시되면 오디오 지원을 확인하세요.

## GitHub 업로드

배포 저장소: https://github.com/MuyoPing/kage-village

`PLAY-GITHUB.luau`는 이 저장소의 고정 커밋 `37069aa3cab4a2b8b8adc1434be7305d2f8d09ee`에서 게임과 자산을 불러오도록 설정되어 있습니다. 실행기에 다음 코드를 넣으세요.

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/MuyoPing/kage-village/main/PLAY-GITHUB.luau"))()
```

저장소에는 KageVillage 게임과 제작 파일만 포함합니다.

`PLAY-GITHUB.luau`의 `BASE_URL`을 다음 형식으로 바꾸세요.

```
https://raw.githubusercontent.com/소유자/저장소/커밋SHA
```

공개 저장소의 raw 접근이 필요합니다. 토큰을 공개 실행 스크립트에 넣지 마세요. 같은 커밋에 코드와 모델·사운드를 함께 올리고 커밋 SHA를 사용하면 파일 버전이 섞이지 않습니다. `manifest.json`은 배포 파일의 크기와 SHA-256 검사 목록이며, 클라이언트의 암호학적 검증 기능을 의미하지는 않습니다.

## 조작

| 키 | 기능 |
|---|---|
| WASD / 마우스 | 이동 / 시점 |
| Shift | 달리기, 기력 소모, 괴물이 듣는 거리 증가 |
| E | 입장, 봉인 회수, 종, 탈출 |
| F | 등불 |
| M | 음량 순환 |
| Q | 높음 / 성능 우선 그래픽 |
| Backspace | 원래 맵 시점으로 복귀 |
| R | 마을 밖에서 입구 재배치 |
| Delete | 마을 밖에서 스크립트 제거 |

데스크톱 키보드·마우스 조작을 기준으로 만들었습니다. 모바일 조작은 포함하지 않았습니다.

실행 파일의 `Language="en"`으로 바꾸면 영어 UI로 시작합니다. 원래 게임의 카메라·조명을 변경하는 다른 스크립트와 동시에 실행하면 충돌할 수 있습니다.

## 제작 파일

`build_assets.py`가 모델 및 사운드의 제작 원본입니다. Python 3과 numpy로 재생성합니다. 환경 모델은 `assets/village.json`, 괴물은 `assets/monsters.json`, 사운드는 `assets/audio/`에 있습니다. 외부 게임이나 마켓플레이스의 모델·음원을 복제하지 않았습니다.
